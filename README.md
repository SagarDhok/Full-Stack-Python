## 🚀 Getting Started

### Prerequisites
- Python 3.8+
- Node.js & npm (for React projects)
- pip (Python package manager)

### Running a Django Project
```bash
cd Backend/DjangoPrograms/<ProjectName>
pip install django
python manage.py migrate
python manage.py runserver
```

### Running a REST API Project
```bash
cd Backend/RESTApiPrograms/<ProjectName>
pip install django djangorestframework
python manage.py migrate
python manage.py runserver
```

### Running a React Project
```bash
cd FrontEnd/React/!Practice/<ProjectName>
npm install
npm start
```

### Running Python Scripts
```bash
cd Backend/PythonPrograms/<TopicFolder>
python <script_name>.py
```
